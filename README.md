# MathVerse 🚀

An interactive educational platform built on **Gamification** and a futuristic tech city environment.  
Users appear as **Future Engineer Explorers**, navigating the world with **W A S D** or arrow keys, collecting experience points (XP) to progress.

---

## ✨ Key Features
- 🎮 **Interactive Navigation** inside a futuristic tech city.
- 🧑‍💻 **3D Avatar Builder** for personalized exploration.
- 📊 **Explorer XP System** starting at 150/1000 points.
- 🏙️ **Educational & Exploratory Environment** focused on math and technology.
- 🔄 **Learning Through Play (Gamification)** to boost engagement.

---

## 📂 Project Structure
- `index.html` : Entry point for the interface.
- `src/` : Contains components and core logic.
- `package.json` : Dependencies and scripts.
- `vite.config.js` : Development environment configuration.

---

## 🛠️ Tech Stack
- **JavaScript** (98%)
- **CSS** & **HTML**
- **Vite** for build and dev server
